# 로컬 PDF 그림 전사

문제은행 레포를 연 세션에서 PDF 파일과 쪽 범위로 시작한다. 첨부 파일은 세션에 표시된 로컬 경로를 사용한다. 이 모드는 로컬 파일에서 읽고 로컬 파일로 결과를 남긴다.

1. **쪽 확인.** 별도 표기가 없으면 PDF 뷰어의 파일 기준 쪽 번호를 사용한다. 첫 페이지가 1이며 범위의 양 끝을 포함한다. `pdfinfo`로 전체 쪽 수를 확인하고, 지면 쪽 번호로 요청받으면 파일 쪽과 대조해 대응을 기록한다. 출력 경로가 주어지면 그곳을 쓰고, 기본값은 `_workspace/figure-transcribe-local-<PDF 파일명>-p<시작>-<끝>/`이다. 다른 입력의 산출물이 있는 폴더는 피한다.
2. **지면 확인과 크롭.** 지정한 모든 쪽을 PNG로 렌더해 직접 연다. 문항의 도형·그래프·표와 그림으로 된 보기를 찾고, 글자·눈금·보조선·채색 영역·그림에 속한 조건이 모두 들어오도록 자른다. 지문과 머리말은 크롭에서 제외한다. 파일 쪽 번호와 지면 읽기 순서로 `p0002-01/`처럼 폴더를 만들어 `original.png`를 저장한다. 문항 번호는 지면 표기 그대로 기록하고 불명확하면 그 사실을 적는다.
3. **DSL 작성과 렌더.** 레포 루트에서 아래 명령으로 현재 DSL 명세를 읽고 [그림 전사 유의사항](lessons.md)의 좌표·라벨·시각 대조 규칙을 적용한다. 그림마다 `figure-dsl/v0` 객체를 `figure.json`에 저장한다. 로컬 렌더러에 원본 크롭을 주어 검증하고 `render.png`를 생성한다. 렌더에는 레포의 Node 의존성과 Chrome 또는 Chromium이 필요하다.
4. **시각 대조.** 각 원본 크롭과 렌더 PNG를 직접 열어 같은 표시 폭에서 확인한다. 도형과 교점의 관계, 라벨·숫자 위치와 가독성, 눈금·화살표, 실선·점선과 색·음영을 확인한다. 그래프는 원점과 기준 눈금 간격도 맞춰 글자 높이, 글꼴·중심 위치, 주 곡선과 보조선의 상대 굵기, 빗금 간격을 대조한다. 원본에 있는 선 겹침과 렌더가 새로 만든 겹침을 구분한다. 고칠 수 있는 차이는 보정하고 새로 렌더한 PNG를 다시 본다. 원본에서 확인할 수 없거나 DSL로 충실히 옮길 수 없는 부분은 추측으로 채우지 않는다.
5. **마감.** 출력 폴더의 `review.md`에 입력 PDF, 파일 쪽 범위, 쪽별 그림 수(0건 포함)를 기록한다. 각 그림의 파일 쪽·문항 번호 또는 지면 위치, 상대 경로, 대조 판정과 근거를 남긴다. 판정은 `대조 완료`, `보정 필요`, `원본 유지`, `검증 미완료` 중 하나로 적는다. 전사나 렌더를 마치지 못한 그림도 `original.png`와 사유를 남긴다. 검증이 통과하고 실제 PNG를 대조한 그림만 완료로 센다. 최종 답변에 대조 완료 및 예외 건수와 출력 경로를 준다.

## 명령 예시

PDF 파일 기준 2~3쪽을 200dpi로 렌더하는 예시다. `page`는 출력 접두사다. 원하는 쪽의 지면 PNG에서 잰 픽셀 좌표로 같은 DPI에서 그림을 자른다. `original`은 PNG 확장자를 뺀 접두사다. 조밀한 지면은 DPI를 높여 같은 방식으로 처리한다. Poppler가 없으면 PyMuPDF로 필요한 쪽을 PNG로 렌더하고 같은 이미지에서 픽셀 좌표로 자를 수 있다.

```sh
pdfinfo "input.pdf"
pdftoppm -png -r 200 -f 2 -l 3 "input.pdf" "page"
pdftoppm -png -singlefile -r 200 -f 2 -l 2 -x 120 -y 150 -W 440 -H 390 "input.pdf" "p0002-01/original"
```

레포 루트에서 명세를 읽고, 만든 `figure.json`을 검증해 렌더한다. 경로는 작업 폴더에 맞게 바꾼다.

```sh
npx --no-install tsx -e "import { buildFigureDslDoc } from './lib/figure-review-export'; process.stdout.write(buildFigureDslDoc())"
npm run figures:render -- "p0002-01/figure.json" "p0002-01/render.png" --original "p0002-01/original.png"
```
