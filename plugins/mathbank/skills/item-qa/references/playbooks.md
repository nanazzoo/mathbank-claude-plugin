# item-qa 플레이북 — 풀이 · 반례 탐색 · 그림 읽기 · 동치 판정

googlarz/math-skill 의 절차에서 착안해 우리 문항(고교 공통수학·수Ⅰ·수Ⅱ·미적분·확통·기하, 중등 일부)에 맞게
줄였다. 솔버는 「풀이 절차」만, 판정관은 전부 읽는다.

## 풀이 절차 (솔버·판정관 공통)

1. **조건 목록부터** — 지문의 조건을 번호로 적는다(정의역·정수 조건·"서로 다른"·"최댓값/최솟값"·단위).
   빠뜨린 조건이 오답의 가장 흔한 원인이다.
2. **묻는 것 확정** — 값인가, 개수인가, 합인가, 보기 번호인가. "모든 실수 k 의 값의 합"을 k 하나로 답하지 않는다.
3. **풀이** — 교과서 표준 경로로. 발상이 두 갈래면 둘 다 짧게 해 보고 같은 값이 나오는지 본다.
4. **검산** — 답을 원래 조건에 대입한다. 방정식은 근 대입, 부등식은 경계·내부 한 점, 극값은 도함수 부호표,
   경우의 수는 작은 경우 손 나열과 공식 비교. 계산이 길면 `sympy_verify` 나 `python -I` 로.
5. **객관식** — 고른 보기 말고 나머지 보기도 하나씩 틀린 이유를 확인한다. 두 보기가 다 맞아 보이면 조건을 다시 읽는다.
   ㄱ·ㄴ·ㄷ 합답형은 각 명제를 따로 참/거짓 판정한 뒤 보기와 맞춘다.

## 반례 탐색 (판정관 — key_error·transcription_error 의 증거)

"정답표가 틀렸다"는 주장은 **반례 하나 또는 대입 하나**로 보여야 한다.

| 문항 꼴 | 증거 만드는 법 |
| --- | --- |
| 방정식·값 구하기 | 정답표 값을 원 조건에 대입해 깨지는 식을 적는다. 내 값은 성립함을 같이 |
| 최댓값·최솟값 | 정답표 값보다 더 크거나(작거나) 조건을 만족하는 점 하나를 찾아 적는다 |
| 개수·경우의 수 | 작은 매개변수로 전수 나열(`python -I` itertools)해 공식과 비교 |
| ㄱ·ㄴ·ㄷ 명제 | 거짓이라 주장하는 명제에 구체적 반례 함수·수열·수를 적는다 |
| 항등식·부등식 증명형 | 특정 값 대입으로 성립 여부를 확인(증명 대신 반례만) |
| 그래프·극한 | 수치 표본(x→a 근처 몇 점)으로 경향을 보이고 sympy limit 로 확인 |

- 반례가 안 찾아지면 `key_error` 가 아니다. `ambiguous` 또는 `solver_error` 를 다시 검토한다.
- 해설에 계산 실수가 있으면 그 줄을 인용하고 맞는 계산을 옆에 적는다.

## 그림 읽기 (솔버·판정관)

1. **슬롯 먼저** — 캡션의 슬롯이 `stem`·`choice` 인 것만 문제 그림이다. `explanation` 은 해설 그림(솔버는 보지 않는다).
2. **읽은 것을 글로** — 좌표·길이·각·눈금·교점을 note 에 먼저 적고 그 값으로 푼다. 눈대중 값은 "약"으로 표시.
3. **그림 ≠ 축척** — "그림은 실제와 다를 수 있다" 전제. 그림에서 잰 길이로 답을 정하지 않는다. 조건과 라벨로만.
4. **그래프** — 축 눈금 간격·원점·점근선·열린/닫힌 점(○/●)을 확인. 열린 점 하나가 정의역 답을 바꾼다.
5. **도형** — 표시된 직각·같은 길이 표시(틱)·평행 표시를 조건 목록에 올린다. 표시 없는 직각은 가정하지 않는다.
6. 크롭이 잘려 라벨이나 축이 안 보이면 `skip`(솔버) / `undecidable` 또는 원본 지면 대조(판정관).

## 동치 판정 (판정관 — equivalent_notation 판단)

비교기(`scripts/compare_answers.py`)는 번호 정규화·SymPy 동치·수치 대입까지 한다. 그래도 못 맞추는 꼴:

| 꼴 | 예 | 같다고 보는 기준 |
| --- | --- | --- |
| 해집합·구간 | `x<-1 또는 x>3` ↔ `(-\infty,-1)\cup(3,\infty)` | 경계값·열림/닫힘이 같다 |
| 순서쌍·좌표 | `(1, 2)` ↔ `x=1, y=2` | 성분이 같다 |
| 근의 나열 | `x=1 또는 x=2` ↔ `1, 2` | 집합이 같다 |
| 근사·반올림 | `\sqrt{2}` ↔ `1.414` | **같지 않다** — 정답표가 정확값이면 근사는 오답 |
| 단위·꼴 | `30°` ↔ `\frac{\pi}{6}` | 문항이 묻는 단위가 정한다 |
| 합답형 | `ㄱ, ㄷ` ↔ 보기 `③`(ㄱ,ㄷ) | 보기 내용으로 대응해 같다 |

- 판정관이 `equivalent_notation` 이라 판정한 꼴은 README 「비교기 개선 후보」에 꼴과 예를 남긴다 —
  같은 꼴이 두 배치 이상 나오면 비교기에 넣는다.
- `acceptedValues` 에 다른 표기가 빠져 학생 채점이 틀릴 수 있는 꼴이면 `fix` 에 "acceptedValues 추가: …" 로 적는다
  (정답표 오류는 아니지만 채점 정확도 문제다).
