# 수동 추출 — 교재 공통 함정 (배치 간 누적)

> 48개 배치(2026-09-03 ~ 09-15, `docs/claude/*수동추출*/`)에서 **교재를 바꿔도 다시 나온** 함정만 모은다.
> 교재·장 고유 규칙은 각 배치의 `SPLIT.md` 가 정본이고, 여기는 "처음 보는 교재에서도 먼저 의심할 것" 목록이다.
> 새 배치에서 같은 유형이 또 나오면 한 줄 추가한다(L-번호 이어서).

## 범위·쪽

- **L-1** `extract_status` 의 `nextUnextracted` 는 "본문 잡이 안 덮은 쪽"이라 **해설 면·표지·쉬어가기도 미추출로 잡는다**. 쪽을 고르기 전에 지면을 한 번 본다(문서 11 "미추출 7~9쪽"이 실은 정답 및 해설).
- **L-2** 수능·모의고사는 **홀수형/짝수형이 같은 문항**이다. 한쪽만 옮긴다 — 둘 다 옮기면 통째로 중복.
- **L-3** 수능은 선택과목마다 번호가 **23번부터 다시** 시작한다. 같은 문서에 같은 번호가 여럿 생겨도 유니크 제약(`extractionJobId, extractionItemIndex`)은 안 걸리지만 등록 화면에서 헷갈린다 — README 특이점에 적는다.
- **L-4** 쪽 오프셋(PDF 쪽 ↔ 인쇄 쪽)은 교재마다, 본문/해설마다 다르다. 꼬리말 쪽 번호로 **양 끝을 실측**해 README 「쪽 오프셋 규칙」에 적는다. 별책 해설은 `answer_key_path` PDF 쪽 기준.
- **L-5** 장 경계 해설은 앞뒤 장과 한 쪽을 공유한다 — `--key-*` 는 양 끝 한 쪽씩 겹쳐 잡고, 마감 때 "다음 장 해설 시작 쪽·시작 번호"를 실측해 장 범위 표를 고친다.
- **L-6** 각 장 첫 쪽(개념 정리)은 산출 0이 정상이다. 범위에 넣되 0건을 결손으로 보지 않는다.

## 머리말·꼬리말을 믿지 말 것

- **L-7** 본문 머리말 `정답 및 풀이 0NN쪽`, 해설 머리말 `본책 N~M쪽` 은 **펼침면 단위**라 실제 내용과 어긋난다. "홀수 쪽에만", "코너 시작 쪽에" 같은 규칙도 장마다 깨졌다. **문항 ↔ 해설 매칭은 항상 문항 번호로** 한다.

## 지면 메타 (stageMark · difficultyMark)

- **L-8** 한 쪽이 좌·우단으로 **서로 다른 코너/유형**일 수 있다(유형 익히기 | 유형↑, 서술형 | 실력 UP). `stageMark` 는 **단 단위**로 판정한다 — 쪽 단위로 찍으면 한 단이 통째로 틀린다.
- **L-9** 쪽 최상단의 **작은 반복 배너**(예: `시험에 꼭 나오는 문제`)는 앞 코너의 연속 표시일 뿐이다. 그 쪽 문항의 코너는 문항 바로 위 배너로 정한다.
- **L-10** 난이도 아치는 **덮은 글자 수를 먼저 센다** — 1글자면 하/중/상, 2글자면 중하/중상. 색만 보면 `하`(순노랑)와 `중하`(연주황)가 헷갈린다. `중요` 핀은 아치와 폭이 같을 수 있어 y 위치로 구분.
- **L-11** 아치가 인쇄되지 않는 지면(시험에 꼭 나오는 문제 등)은 `difficultyMark: null` 로 둔다. 지면 매핑값은 임시값이라 **등록 후 판정관이 문항 단위로 재판정**한다(지면 단위로 대상을 잡는다).

## 판독 기법

- **L-12** 작은 첨자·분수 지수는 `extract_pages_read(…, zoom: true)` 의 상·하 확대본으로 다시 본다. 확신 없는 표기는 「확신 없음」으로 보고.
- **L-13** 행 투영으로 번호↔박스를 맞출 때 **홀수 쪽 오른쪽 세로 탭**(x≈1195~1240 @1300폭)을 빼야 한다 — 안 빼면 한 칸씩 밀린다.
- **L-25** 원본 영역 `region {x,y,w,h}` 은 **쪽 전체 기준 0~1** 이다 — `zoom` 확대본(상·하 반쪽)에서 잰 값을 그대로 쓰면 y 가 절반으로 틀어진다. 문항 번호 박스 왼쪽 위에서 다음 문항 직전까지, 단 폭으로(2026-10-12 S2). 틀린 상자보다 빈 값이 낫다.
- **L-14** 그림 문항은 쪽 번호가 크롭 소스와 같아야 한다 — 쪽을 잘못 적으면 크롭이 통째로 어긋난다. 두 그림이 붙어 있으면 크롭 맞바뀜을 마감 확인 요청에 남긴다.

## 해설·정답

- **L-15** 풀이 없이 `답` 만 인쇄된 문항은 `explanationLatex: null`. 풀이를 지어내지 않는다.
- **L-16** 보기 판정형 해설은 참값을 적고 `(거짓)` 을 붙이는 조판이 있다 — 해설 문장을 정답으로 옮기지 말고 판정 결과를 옮긴다.
- **L-17** 교재 오식 의심(단서 누락, 정답표와 해설 불일치)은 **고치지 않고** 원문대로 옮긴 뒤 「확인 요청」에 남긴다.
- **L-18** 정답 표기 통일: 분수는 `\frac{a}{b}`(`a/b` 혼재 금지), `answer` 에 좌변(`f(x)=`) 넣지 않기, 인라인 `\displaystyle` 쓰지 않기 — 배치 마감에서 반복 지적된 것들.

## 전사 재발 유형 (2026-10-12 전사 감사 116문항 — `docs/claude/2026-10-12-수동추출-그림전사-점검/01_transcription-audit.md` 「축별 소견」)

- **L-26** 해설 C단계의 단계 머리(`1st`·`2nd`·`3rd`)는 빼지 않는다 — 원문 줄 머리 그대로 `\textbf{1st}\ ` 처럼 옮긴다(1211~1216·1054~1057 에서 빠짐).
- **L-27** 서술형 채점 기준표(❶ 50%·❷ 50% 등)는 해설 끝에 한 줄로 옮긴다 — 예: `채점 기준: ❶ 근 구하기 30\% / ❷ … 60\%`(1212·1214 누락, 같은 문서 6509 는 수록).
- **L-28** 해설 속 그래프를 옮기지 않으면 "오른쪽 그림과 같으므로"를 그대로 두지 않는다 — `[그림]` 마커로 그림을 싣거나 문구를 "그래프를 그려 보면"으로 바꾼다(0038 에 고아 문구 3개). 지문도 "오른쪽 [그림]" 말고 `[그림]` 만.
- **L-29** 정답은 지면 표기 그대로 — `±` 를 전개하지 않는다: `3, \frac{-3\pm3\sqrt{3}i}{2}`, `\pm3i, \pm3`(0002·0004 에서 "3i, -3i, 3, -3" 로 풀어 씀). 분수는 L-18 대로 `\frac`(쎈 미적분의 `1/6`·`-1/2` 평문 금지).
- **L-30** 정답 값 끝에 문장부호를 붙이지 않는다 — `없다`(✕ `없다.`, 0004). 자동 채점 동치 판정이 마침표에서 깨진다.
- **L-31** 표 보기(㈎~㈑ 열 표)를 한 줄로 바꾸며 안내 문구("(차례로 ㈎, ㈏, …)")를 **지어 넣지 않는다** — 표로 옮기고, 못 하면 원문 순서대로 한 줄 나열한 뒤 「확인 요청」에 남긴다(1094).
  **예외(2026-10-19 사용자 결정, 잡 131 6번)**: 보기가 값 쌍 표(열 머리 `Q(-2)`·`R(1)`)면 열 머리를 보기마다 반복하지 않는다 — 지문 끝에 `(보기는 차례로 $Q(-2)$, $R(1)$의 값)` 한 번, 보기는 `19,\ 17` 처럼 값만.
- **L-35** 직접 쓴 해설은 **조판**한다(2026-10-19 사용자 지시): 단계마다 줄바꿈(`\n`), 핵심 식은 `$$…$$` 별행, 문장·수식 사이 띄어쓰기, 결론 한 줄. 한 문단에 다 붙이면 화면에서 읽기 어렵다(잡 130 해설 22건 전부 재작성).
- **L-32** 지문 밑줄은 `<u>` 로 살린다 — "옳지 <u>않은</u> 것은?", "<u>없는</u>"(6443 누락).

## 검산식 (SymPy 명세)

- **L-19** `none` 은 SymPy 로 **값 대조가 정말 안 될 때만**(보기 판정·명제·개수 세기·범위·복수값·증명). 어려워 보인다고 눕히지 않는다 — 적분 장은 none 이 3건이었다.
- **L-20** 부정적분 정답의 `+C` 는 검산식 끝에 `+ C` 를 붙이면 그대로 통과한다(`integrate(...) + C`). `expression` 으로 눕히지 않는다.
- **L-21** 단위가 붙은 답(`m/min`, `cm^3/s`, `\mathrm{}` 복합 단위)은 파서 함정이 있었다 — 실패하면 단위를 뗀 값으로 검산식을 쓰고 보고.
- **L-22** 다계수 항등식은 `Poly(...).all_coeffs()` + `solve(..., dict=True)[0]`, 몫 함수 임계점은 `simplify` 후 `solve` — 배치에서 통했던 수법.

## 운영

- **L-23** 원격 MCP 가 401 `토큰 모양이 아닙니다` 면 `MCP_REMOTE_TOKEN` 이 빈 채로 세션이 뜬 것 — 영구 env 로 박고 새 세션.
- **L-24** 전사관끼리 같은 파일(SPLIT.md)을 동시에 고치지 않는다 — 진행 로그는 메인이 보고를 받아 append.
- **L-33** 검산기 샌드박스(`sympy_verify`·`extract_pages_apply` specs)는 **식 하나**만 평가한다 — `lambda`·리스트/제너레이터 컴프리헨션·
  키워드 인자(`solve(..., dict=True)`)·`Eq(...)` 는 `invalid syntax`/`cannot assign` 으로 떨어진다(2026-10-19 잡 129 에서 12건). `solve(...)[0]`·
  `solve([...],[a,b])[a]`·`Poly(...).all_coeffs()[i]`·`.subs(x, v)`·`max(p, q)` 같은 호출 연쇄로 쓴다. `max(list)` 도 "not comparable" — 원소를 풀어 쓴다.
- **L-34** 해설 지면이 없는 문서(기출 시험지)는 전사관이 **직접 풀어** `answers`(page 없음)·`explanationLatex` 를 쓴다(2026-10-19 사용자 지시).
  서버는 `page` 없는 해설 줄도 번호로 붙인다(`answerKeyPage` 만 비운다). 적재 결과는 DRAFT — VERIFIED 는 `verify_ids`·판정관·사람 승인 뒤다.
